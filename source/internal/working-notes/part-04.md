## 2.13 Status-cleanup notes: current position versus resolution history

**METHOD / HISTORICAL CLEANUP**

The old formal vocabulary **Open / Owed / Dropped** is retired.

It mixed two different questions:

1. **Where does a claim stand now?**
2. **What happened to the earlier way we framed it?**

Use the current Working State grammar instead.

### Current position

- **DERIVED / CONSEQUENCE**
- **CANDIDATE CORRESPONDENCE**
- **COMPLETION PENDING** — mechanism exists; calculation, mapping, formalisation, or other completion is missing.
- **UNRESOLVED MECHANISM** — the mechanism / criterion itself is missing.
- **NOT ESTABLISHED** — permitted or suggested, but not earned as ground.
- **GUARDRAIL** — wording or ontology that must not be imported.

### Resolution history

Use **REPHRASED, REFRAMED, CONCLUDED, NARROWED, REDIRECTED, SUPERSEDED,** or **PROVEN AGAINST**.

“Proven against” means the proposed formulation conflicts with already-derived framework structure. It does not mean experimentally falsified unless the note explicitly says so.

> **A deduction does not owe the hoped-for answer. It owes a consequence.**
>
> **The route can fail while the deduction succeeds.**

This is especially important in this framework because a route that cannot do its original job often returns a nearby positive result. Examples include uniform local rate shift resolving into the ruler principle and cross-ground comparison, closure resolving into stabilisation, and exact opposition resolving into an excluded relational limit.

### Maintenance rule

Once a mechanism exists, do not leave the item under **Unresolved mechanism** merely because numbers or physical mapping are hard.

Once an earlier formulation changes, record **how it resolved** rather than calling it “dropped” by default.

### Lane 7 language / translation example

**UNSETTLED CLASSIFICATION / HOSTED EXAMPLE**

Language provides an example where a unit of logic can be converted through a translator and re-expressed as another unit of logic.

This demonstrates that higher-Lane exchange / establishment-like capacity can operate **hosted** through human, linguistic, and tool structure.

It does not establish an independently seated Rung.

There is also a classification issue:

- Lane 7 concerns establishing a logic as new ground;
- Lane 10 concerns exchange / conversion between already-established logics.

Word-for-word translation may instantiate part of one or both depending on whether the result merely converts an existing logic or actually establishes a new one.

Do not force the example into one Lane until the distinction is derived more sharply.

### Reflection cleanup

The old “why reflection preserves angle” item is no longer an unresolved mechanism for a uniform boundary.

Current structural account:

`boundary distinguishes normal traversal`
→ `normal relation reverses`
while
`uniform tangential relation is not newly distinguished`
→ `tangential relation is preserved`

The remaining work is physical / wave-optics completion, not the basic angle symmetry.

## 2.14 Deduction cadence

**METHOD**

Work through unresolved framework questions **one at a time**, rather than trying to clear a large open list in one discussion.

Default cadence: roughly one major open frontier per day unless the user deliberately continues the same branch.

Reason:

- status confusion compounds into later deduction confusion;
- each resolved mechanism should first be promoted, reclassified, and synced before the next frontier is opened;
- a smaller active queue makes accidental resurrection of stale questions less likely.

This is project workflow, not framework ontology.

## 2.15 Color as established hosted logic and shared relational direction

**UNSETTLED / FUTURE DEDUCTION LEAD / BIOLOGICAL-COGNITIVE TERRAIN**

Preserve this branch without promoting it into Lane/Rung ground yet.

The proposed distinction is not merely that humans learn common **words** for colors.

The stronger possibility is that **color itself is already a stable logic seated through biological ground** before explicit linguistic teaching.

Working separation:

`incoming physical relation`
≠
`color logic through which the host resolves it`
≠
`word / cultural label later attached to that color logic`

Language is a useful comparison because both can become broad reusable conceptual ground, but much of language's detailed structure is explicitly transmitted between hosts.

Color appears to have a stronger pre-linguistic / biological seating in the user's proposed reading.

### Same direction, not identical private experience

Do **not** phrase the question as:

> "Do all people literally experience the same private red?"

The useful target is relational:

> **Why do independently hosted organisms tend to resolve color relations in strongly compatible directions?**

The user specifically points to apparent agreement not only in ordering / direction but also in surfaced opposed positions within color organisation.

This could be relevant to the existing rule that binary or opposed surface bookkeeping need not imply a binary / exact-antipode ontology underneath.

So preserve the possibility that color has stable **surface oppositions** while the deeper relational structure remains richer and does not require an exact relational 180° antipode.

### Coarse grain, enormous scope

Color may be a strong example of:

> **grain and scope are independent.**

A color distinction can remain coarse with respect to object, material, cause, exact spectrum, context, and use while binding into a very large number of later relations.

Candidate bindings include:

- object recognition;
- attention;
- warning / salience;
- food and environment;
- memory;
- learned symbols;
- language;
- affect / emotion;
- higher conceptual association.

The user's intuition is therefore not that color must be finely specified because it has large effects.

It may instead be:

`coarse stable color logic`
→ `very broad reuse across later relations`
→ `large conceptual / behavioural reach`

### Near the Lane / Rung boundary

This is useful terrain for the newly active distinction:

`represented through host`
≠
`established / reusable logic in host`
≠
`independently seated Rung`

Color may be an example of the middle condition: genuinely established enough to constrain later resolution and act as ground, while still seated through biological host structure rather than standing as a new independent Rung.

Language may occupy a related but differently acquired hosted regime.

Do not assign color itself a Lane or Rung merely because the logic is established.

### Future questions, one at a time

When this branch is revisited, useful questions include:

1. What exactly would count as evidence that color logic is established ground rather than only repeated representation?
2. Which parts of color topology are stable across independently developing hosts, and which are learned or host-specific?
3. Does agreement in relational direction follow from shared biological ground, shared environmental constraint, or both?
4. How does a coarse color distinction acquire such broad consequential reach into emotion and other concepts?
5. Does this give a concrete hosted example relevant to Lane 8's aim of established logic becoming ground, without implying an independently seated Rung 8?

Do not answer all of these at once. Preserve the one-major-frontier-per-day cadence.
