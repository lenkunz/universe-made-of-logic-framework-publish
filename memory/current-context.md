## Current core picture

- Relation is primitive.
- The deepest first Cut is relation: `A → R_AA`.
- `R_AA` is self-differentiation of one undivided ground into distinguishable relational roles, not an ordinary self-loop between already-finished copies.
- A relation is a distinction held together: split preserves difference; sync preserves enough common ground for the distinction to remain one relation.
- Once roles are referable, local bookkeeping can write `A + B → A + B + R_AB`.
- Points/domains are grain-relative. Being one can itself be a relational achievement.
- A stable relational composition can participate as one at another grain without resetting ontological Level 0.

## Cut, resolution, possibility, Aim

The newest foundational correction is:

`Cut / relation seats`
→ `a distinction becomes consequential`
→ `that distinction is resolved at that grain`

The same relation simultaneously leaves an open remainder:

`what the Cut does not distinguish`
→ `remains equivalent / possible relative to the new ground`

So the resolved face and open face are two readings of one seated relation.

Aim is not a separate substance or layer waiting to enter topology. If an Aim is real as a present constraint, it is already seated relational topology at its grain. A coarse Aim can be fully resolved as a present constraint while leaving many fine implementations unresolved.

Former question:

`How does Aim become topology?`

is concluded/narrowed.

Remaining completion problem:

`already-seated coarse Aim + other present ground + relational cost`
→ `which finer distinction becomes consequential next?`

Do not infer that the first Cut is conscious Aim. Bias is more general; Aim is a richer higher-order case.

## Budget and relational iteration

The personal-origin intuition that helped sharpen budget was a split/sync cadence experienced introspectively and associated by the user with brainstem-level organisation. Treat that as motivation, not empirical neuroscience.

The framework-native correction is:

- Budget is not universal time.
- It is better read as resolving participation / relational iteration capacity.
- What is common is not an external second advancing everywhere.
- A relation advances when enough work relative to that relation has been completed for another consequential iteration of that relation.
- Different relations can therefore carry radically different effective work while remaining mutually related through inherited relational ground.

Earlier shorthand:

`1 + 1 → 1 + 1 + 3`

Safe reading:

`1_A + 1_B → 1_A + 1_B + 1_[A,B,R_AB]`

The `3` means relational span over the composed participant `[A,B,R_AB]`, not three extra universal clock ticks.

Strong compression:

> Budget composes through relation. Cadence does not need to become universal time.

A CPU analogy remains useful only as work-per-clock / architecture, not literal clock-frequency ontology.

## Coarse and fine

Keep these separations fixed:

`grain ≠ scope`

`coverage ≠ resolution`

`stored ≠ accessible ≠ presently rendered`

Coarse means real undercommitment relative to the consequential grain, not blurry, weak, unfinished, old, sparse, or less real.

A coarse relation can govern a huge implementation class while resolving very little fine detail. This is why Lane and Rung can become far apart in scope without being far apart in kind.

Potential further insight currently exploratory:

Fine and coarse may differ partly in what counts as one completed relational iteration. A coarse logical relation can act over already-compressed structure without freshly reconstructing every fine distinction underneath it.

## Anchoring

Anchor is relational, size-independent, and not a parent-object hierarchy.

Working definition:

> Relational anchor = already-seated relational ground that another distinction, relation, or domain can reuse as support/reference.

Because `R_AB` becomes shared ground, anchoring can be reciprocal:

- A can anchor B under one question.
- B can anchor A under another.
- Contribution and spend need not be symmetric.

Use a mesh, not a one-way stack:

`atom ↔ molecule ↔ cell ↔ organism ↔ Earth`

A member can become locally bounded while globally freer because membership gives access to reusable support it could not establish alone.
