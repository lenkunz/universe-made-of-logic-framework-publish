# Publication Image Assets

Generated publication images belong here, grouped by article slug.

Example:

- `publish/assets/images/the-possibility-lane/hero-01.png`
- `publish/assets/images/the-possibility-lane/inline-01.png`

The corresponding article Markdown under `publish/articles/` should reference the asset with a relative Markdown link and place an `<!-- Image Caption: ... -->` comment immediately below it.

Because the repository is private, these assets are durable project sources, not public Substack hotlinks. The publication/import step must ingest the image itself for public delivery.
