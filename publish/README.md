# Publish Layer

This folder is the standing publication pipeline for the **Universe Made of Logic / My GUT Deduction** framework.

`source/` owns semantic meaning.
`memory/` owns continuity and reasoning context.
`publish/` owns reader-facing rebuilds, publication identity, embedded publication assets, and reusable Work prompts.

## Default flow

`discussion / semantic change`
→ `source/ sync`
→ `publish manifest identifies affected published article(s)`
→ `Work reads source + publish rules`
→ `Work rebuilds publication Markdown`
→ `Work generates publication images`
→ `images are committed under publish/assets/images/`
→ `Markdown embeds those images`
→ `public QA / Substack update`

This is the default publication path from now on.

## Structure

- `manifest.md` — registry of the maintained publication set and whether each item is already published.
- `guidelines.md` — standing publication and image rules.
- `prompts/` — reusable Work prompts.
- `articles/` — publication-ready Markdown outputs generated by Work.
- `assets/images/` — generated publication images, grouped by article slug.

## The maintained framework publication set

The primary set contains eight articles:

1. Basics I — Resolution costs
2. Basics II — Coarse is not blurry, weak, or absolute
3. Basics III — One and one make three
4. The Index of the Framework
5. A Universe Made of Logic — Informational Topology Framework
6. The Possibility Lane Framework (P-Lane)
7. The Lane and the Rung
8. Where the Framework Currently Stands

These are treated as **existing publication identities to update**, not as eight new articles to invent from scratch.

The Hope remains separate personal/metaphysical material and is not part of this eight-article canonical publication set unless explicitly requested.

## Source of truth

Publication prose must follow the current stable semantic sources under `source/`.

When status matters, use `source/where-the-framework-stands.md`.
When a foundational correction matters, read the relevant file under `source/changes/`.
When article URLs are needed, use `source/internal/url-list.md` and `publish/manifest.md`.

## Images

Generated images belong under:

`publish/assets/images/<article-slug>/`

Publication Markdown under `publish/articles/` should embed them using normal Markdown image syntax and place an image-caption comment immediately below each image.

Because this repository is private, GitHub image URLs are not public Substack hosting. The repository embedding is for durable project packaging and Work automation. A Substack import/paste must ingest the image itself rather than relying on a private GitHub hotlink remaining publicly accessible.
