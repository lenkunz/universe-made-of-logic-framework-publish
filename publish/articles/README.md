# Publication Articles

Work-generated, publication-ready Markdown for the maintained framework belongs here.

Do not pre-fill this directory with stale copies merely to mark an article as published. Publication identity is registered in `publish/manifest.md`.

When Work rebuilds an article, use the stable output path from the manifest and update it in place.

Each final article should already contain:

- article-slot comments where relevant;
- embedded relative Markdown image links;
- image-caption comments directly under images;
- publication-ready reader-facing prose derived from current `source/` semantics.
