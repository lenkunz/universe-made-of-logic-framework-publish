# Why Can Unrelated Things End Up Similar?

Two people can solve the same practical problem without copying each other.

Give them the same narrow doorway, the same awkward box, and the same goal of getting it through. They may independently discover the same trick: rotate the box before the corner reaches the frame.

Nothing mysterious had to pass between them.

The doorway did part of the teaching.

That sounds almost trivial. But the same shape appears in harder questions. Why can separate histories produce similar solutions? Why do patterns recur when there is no shared plan telling each case what to become?

One answer is that **sharing constraints is not the same as sharing a blueprint**.

The doorway does not contain a hidden movie of the correct movement. It simply rules out many movements and leaves others workable. Two independent attempts can therefore be pushed toward the same family of solutions while still differing in timing, grip, angle, mistakes, and everything else the constraint did not decide.

The common result can be coarse while the histories remain different in detail.

That distinction matters.

If two outcomes resemble each other, we often reach for one of two stories:

`one copied the other`

or

`the match is coincidence`.

But there is a third possibility:

`different histories`
+
`some shared constraints`
→
`a recurring family of workable outcomes`.

The framework gives this a particularly clean form.

A present relation does not have to specify every fine detail. It can preserve only the distinctions that matter at its grain. Finer alternatives can remain open until a later relation makes one of them consequential.

So shared ground can narrow the field without choosing one exact future.

That gives us:

`shared constraint`
→ `similar possibilities remain cheap or compatible`
→ `local encounter resolves the detail`

The recurrence comes from the first two steps.

The variation comes from the last one.

This is why the useful line is not:

> The same ground makes the same thing.

It is:

> **Shared constraint produces recurrence, not duplication.**

Two structures can rhyme because they were shaped by some of the same limits without ever becoming copies.

And the limits do not need to be a physical object passed from one to the other. They can be whatever present ground both cases must resolve against: a boundary, an available route, a cost, an already-seated rule, or another relation that makes some continuations easier to sustain than others.

That does **not** mean every resemblance in biology, culture, engineering, or physics should be explained this way. A real case may involve inheritance, communication, common ancestry, direct copying, chance, or mechanisms this framework has not mapped. Similarity by itself does not tell us which story is true.

The narrower framework result is structural.

If separate resolutions encounter enough of the same constraint, similar outcomes do not require a finished pattern to travel between them. The constraint can select a family. The local history can still select the member.

So when unrelated things end up looking strangely alike, the first question need not be:

**What copied what?**

Sometimes the better question is:

**What did both of them have to solve?**
