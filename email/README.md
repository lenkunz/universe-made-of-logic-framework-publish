# Substack Email Copy

Updated: 2026-08-25

This folder contains the current paste-ready email copy for **Pondering of the Universe**.

## Files

- `welcome-free-subscribers.md` — welcome email for a new free subscriber.
- `welcome-paid-subscribers.md` — welcome email for a new paid subscriber.
- `welcome-expired-paid-subscribers.md` — calm transition email when a paid subscription ends.
- `header.md` — short publication header for regular emails.
- `footer.md` — reusable publication footer for regular emails.

## Substack use

Each welcome-email file separates the subject line from the body. Paste only the body into the Substack editor after setting the subject.

The header and footer files contain the reader-facing copy only. Substack's automatic unsubscribe, account, address, and legal elements should remain enabled; they are not duplicated here.

## Subscription stance

The framework itself is not divided into a public version and a secret paid version.

Paid subscription primarily:

- opens the smaller paid comment space;
- helps keep long discussion manageable;
- supports the time behind the publication as a welcome side effect, rather than buying a separate body of ideas.

An expired paid subscription is therefore treated as a change in access, not a rejection, failure, or sad goodbye.
