# Reading the Comparison Figure

The supplied [PNG](scale-comparison-and-planck.png) was created during the discussion immediately before this package. It is retained as a reference with the assumptions printed on it.

## Upper panel

The same three illustrative cycles are drawn at length ratios `exp(-s)` for `s = 0, 0.5, 1, 1.5, 2`. The height of each wave is schematic and separates the rows. It is not a measured field amplitude.

The samples illustrate one scalar rule. `s` accumulates logarithmic contraction; it is not an external time coordinate. The picture does not assign `s` to radial distance from a gravitating object. Length, area, and volume must not be silently treated as the same scale measure.

The right-hand rulers show the same five ratios on linear and logarithmic coordinates. Logarithms turn equal ratios into equal steps.

## Lower panel

The axis is `x = h nu/(k_B T)`. The plotted quantity is Planck radiance per unit frequency at fixed temperature, divided by its peak value.

The bands are:

- first term: `x^3 exp(-x)`;
- second term: `x^3 exp(-2x)`;
- later terms: the remaining infinite sum.

The outline is the exact total `x^3/[exp(x)-1]`, normalized by its peak. This is not an independently measured curve.

At each selected `x`, the repeat factor is fixed across the repeat index. As `x` changes along the horizontal axis, that factor changes. This is the clarification contributed after the picture was drawn.

The ordinary `x^3` weighting and physical definition of `x` were supplied as inputs. The picture therefore demonstrates a conditional bridge; it does not derive them from the framework's budget quantities.

Use this image to understand or illustrate the algebra. It is not a finished conceptual hero. If reused publicly, retain a caption explaining the conditional construction and spectral measure. If edited, preserve the original reference and create a distinct article figure.
