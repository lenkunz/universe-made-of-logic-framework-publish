## Central question

When we build a fine-grain instrument to obtain an object-like result, what does that result establish about the relation before the measurement?

## Central payoff

> **They wish for an object, so they get an object.**

The wish is already a coarse direction within the ontology. It becomes consequential through planning, construction, calibration, and the supported measurement arrangement. The apparatus establishes the fine-grain relational path through which a successful detection must resolve. The resulting object is real at that grain. Its reality does not require every finer distinction, or its whole prior path, to have been fully computed beforehand.

The episode must preserve the wish as part of this account. Replacing it with a correction that says only the apparatus matters would remove the very continuity the author is explaining.
