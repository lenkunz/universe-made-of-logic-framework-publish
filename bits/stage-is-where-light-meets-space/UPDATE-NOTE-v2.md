# Update Note — v2

This revision fixes a missing root mechanism in **Stage Is Where Light Meets Space**.

The original P-lane theory names two orientations of relation:

- **Afference**: relation reaching inward, the perception side of the domain.
- **Efference**: relation reaching outward, the perception side of Space.

Both require budget.

At Stage, relation orientation can flip relative to the anchoring domain:

`Domain A Efference → Stage → Domain B Afference`

A domain can then resolve inward relation and emit a new outward relation.

A recurring loop:

`Afference → domain resolution → Efference → Stage → Afference`

can provide / sustain persistence budget.

This makes Stage an active relational turning interface rather than only a label for measurable reality.
