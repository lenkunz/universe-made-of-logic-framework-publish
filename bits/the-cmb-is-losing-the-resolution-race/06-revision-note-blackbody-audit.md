# Revision Note — Blackbody Audit Correction

Date: 2026-08-30

## What was wrong

The earlier package repeatedly framed the open blackbody problem as:

> **Why does cross-resolution projection preserve a Planck spectrum?**

That imported an assumption the framework had already started questioning: that “the blackbody curve” is an ontological object present before measurement and then transported through a coarse/fine transformation.

## Corrected layer order

The corrected framework order is:

`target relation`
→ `receiver selects periodic comparison grain B_x`
→ `target budget B_t seats against that comparison inside shared anchor`
→ `Stage produces frequency / gain measurement`
→ `sweep B_x`
→ `statistical frequency-intensity distribution`
→ `Planck-law fit`
→ `temperature parameter`

So the first blackbody audit is:

> **Why does the native receiver/target comparison sweep generate the observed Planck statistical relation?**

The cross-era question comes second:

> **Why does changing the target/receiver resolution ratio shift the characteristic scale while the same native comparison rule generates the corresponding distribution?**

## What remains open

- exact mapping from native framework variables to the Planck distribution;
- exact `T(z)` relation;
- high-comparison/statistical occupancy rule;
- whether a native proportional recursion independently forces an exponential;
- anisotropy/acoustic derivation;
- discriminating prediction.

## What must not be claimed

- that the yellow toy curve derives Planck's law;
- that `e` may be imported because the desired formula contains it;
- that the CMB blackbody is already explained by “coarse looks thermal”;
- that the framework has already reproduced standard cosmology quantitatively.

This revision supersedes all “Planck-shape preservation under cross-resolution projection” language in the earlier package.
